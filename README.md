# Дневник питания

Проект предназначен для ведения учёта ежедневного рациона. Он помогает отслеживать калорийность, количество белков, жиров и углеводов, а также анализировать пищевые привычки.

## Категории

- Завтрак
- Обед
- Ужин
- Перекусы

## Как пользоваться дневником

1. Взвесьте порцию еды.
2. Найдите продукт в таблице калорийности.
3. Запишите данные в блокнот или приложение.
4. Подведите итог за день.
